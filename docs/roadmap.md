# PureCam 新增功能规划

> 状态：已确认；第一期开发完成，待真机验收（`phase-1` 分支） · 基于 v0.1.0 · 2026-09-29
>
> 现有功能见 [features.md](features.md)。本文列出计划新增的功能，每项写清交互和实现思路。

## 概要

共四组功能，建议分四期做。每期做完都能单独发版和验收。

| 期 | 内容 | 改动量 |
| --- | --- | --- |
| 一 | 补全现有体验：对焦框、变焦倍数、启动时显示最近一张、记住设置 | 小 |
| 二 | 拍摄辅助：网格线、定时拍摄、音量键拍照、快门声 | 小到中 |
| 三 | 画幅与补光：画幅切换、手电筒常亮、前置屏幕补光 | 中 |
| 四 | 录像 | 大 |

- 全部功能都能在现有的 `LifecycleCameraController` 上实现，不需要换成 `ProcessCameraProvider`。
- 新增三个依赖，都是 AndroidX 官方库：
  - `androidx.datastore:datastore-preferences`：保存设置（第一期）。
  - `androidx.compose.runtime:runtime-livedata`：在 Compose 里读取 CameraX 的对焦、变焦、手电筒状态（第一期，版本由 Compose BOM 管理）。
  - `androidx.camera:camera-video`：录像（第四期，版本与现有 CameraX 库一致）。
- 新增一个权限：`RECORD_AUDIO`，第一次进入录像模式时才申请。

## 已确认的事项

| # | 事项 | 结论 | 未采用的方案 |
| --- | --- | --- | --- |
| 1 | 实施方式 | 分四期，每期验收后再做下一期 | 一次全部做完 |
| 2 | 控件摆放 | 顶栏放闪光灯、定时、画幅；网格线、快门声这类设一次就很少改的，收进顶栏右侧的「⋯」面板 | 全部平铺在顶栏 |
| 3 | 快门声默认 | 默认开，可在「⋯」面板关闭 | 默认关 |
| 4 | 手电筒入口 | 并入闪光灯按钮：OFF → AUTO → ON → TORCH（常亮）循环 | 顶栏单独放一个手电筒按钮 |
| 5 | 9:16 取景布局 | 取景画面铺满屏幕宽度，上下栏半透明叠在画面上 | 取景画面留在上下栏之间，左右留黑边 |
| 6 | 录像画质 | 第一版固定 1080p | 加 4K 或画质选项 |

2026-09-29 确认全部采用建议方案，下文按「结论」一列来写。

## 界面调整

四期做完后，取景页的变化：

| 区域 | 现在 | 规划后 |
| --- | --- | --- |
| 顶栏 | 闪光灯 | 闪光灯、定时、画幅，右侧「⋯」面板（网格线、快门声）；录制中只显示录制时长 |
| 取景框 | 固定 3:4 | 随画幅变形；叠加对焦框、网格线、倒计时数字、变焦倍数 |
| 底栏 | 缩略图、快门、切换镜头 | 不变，快门上方加「拍照 / 录像」切换 |

## 第一期：补全现有体验

### 1.1 对焦框

**交互**

- 点按取景画面，点按位置出现一个白色圆框，从略大缩到正常大小。
- 对焦成功后圆框停留约 1 秒再淡出；对焦失败时圆框变成半透明后淡出。
- 切换镜头或画幅时清掉对焦框。

**实现**

- CameraX 1.5 起，`CameraController.getTapToFocusInfoState()` 会同时给出点按位置和对焦结果，直接用它来画框。不需要自己拦截触摸事件，原有的点按对焦和双指缩放不受影响。
- 圆框用 Compose 绘制，叠在取景框上。

### 1.2 变焦倍数

**交互**

- 双指缩放时，取景框底部居中显示当前倍数，比如 `2.4x`。
- 倍数不是 1x 时标签一直显示，点击标签回到 1x；回到 1x 后标签淡出。
- 部分机型可以缩小到 1x 以下（超广角），比如 `0.6x`。

**实现**

- 读取 `CameraController.getZoomState()` 里的倍数；点击标签时调用 `setZoomRatio(1f)`。

### 1.3 启动时显示最近一张照片

**交互**

- 打开应用时，缩略图直接显示 `Pictures/PureCam` 里最新的一张照片。第四期之后也包括视频。
- 在相册里删掉这一张后回到应用，缩略图自动换成上一张；全部删完就显示空占位。

**实现**

- 每次回到前台时查询一次 MediaStore，按添加时间倒序取第一条。拍照成功后照旧直接更新，不用重新查询。
- 不申请读取相册的权限，因为 Android 10 起应用可以直接读取自己保存的照片。
- 代价：卸载重装或清除应用数据后，以前拍的照片不再算本应用的，缩略图要等拍下一张才会出现。要显示这些旧照片，得额外申请读取相册权限，不建议为此多弹一次权限框。

### 1.4 记住设置

**交互**

- 闪光灯模式、前后镜头在重新打开应用后保持上次的选择。后面几期加的定时、画幅、网格线、快门声也一样。
- 两个例外：手电筒常亮不记忆（见 3.2），拍照 / 录像模式也不记忆（见 4.1）。

**实现**

- 用 DataStore 保存，新建 `settings/CameraSettings.kt` 统一管理所有设置项。
- 设置读取完成后再绑定相机，避免上次用的是前置、这次却先打开后置再切过去。读取只要几毫秒，用户察觉不到。

## 第二期：拍摄辅助

### 2.1 网格线

**交互**

- 在「⋯」面板里开关，默认关。
- 开启后取景框上显示九宫格：横竖各两条半透明白色细线。换画幅时跟着取景框重新三等分。
- 网格线只显示在屏幕上，不会拍进照片。

**实现**

- 在取景框上叠一层 Compose `Canvas` 画线。

### 2.2 定时拍摄

**交互**

- 顶栏定时按钮，点击按 关 → 3 秒 → 10 秒 循环。
- 开启后按快门开始倒计时，取景框中央显示大号倒数数字；倒计时中再按一次快门就取消。
- 倒计时期间，除快门以外的按钮暂时不可用。
- 应用切到后台时自动取消倒计时。
- 第一版只有画面上的倒数，没有提示音。
- 录像模式下不显示定时按钮。

**实现**

- 用协程每秒更新一次倒数，结束时拍照；离开取景页或切到后台时取消协程。

### 2.3 音量键拍照

**交互**

- 在取景页按音量加键或减键，效果等同于按快门：拍照、开始 / 取消倒计时、开始 / 停止录像。
- 按住不放只触发一次，不会连拍。
- 在授权页等其他界面，音量键照常调音量。

**实现**

- 在 `MainActivity.onKeyDown()` 里拦截音量键并转发给取景页。只在取景页显示时拦截，其他时候交给系统处理。
- 按住产生的重复按键事件（`repeatCount > 0`）直接忽略。
- 转发的按键和快门按钮走同一段逻辑，所以同样会在相机初始化完成前不响应。

### 2.4 快门声

**交互**

- 在「⋯」面板里开关，默认开（见待确认事项 3）。
- 拍照时播放系统快门声；开始和结束录像时播放系统提示音。
- 在要求拍照必须有快门声的地区（比如日本、韩国），快门声无法关闭，面板里的开关置灰。

**实现**

- 用系统的 `MediaActionSound` 播放声音。
- 在 CameraX 1.4 起提供的 `onCaptureStarted()` 回调里播放，这个时刻相机刚开始曝光，声音和实际拍摄时间对得上。现有的取景画面闪黑也挪到这里触发。
- 用 CameraX 的 `CameraInfo.mustPlayShutterSound()` 判断当前地区是否强制快门声。

## 第三期：画幅与补光

### 3.1 画幅切换

**交互**

- 顶栏画幅按钮显示当前比例，点击按 3:4 → 9:16 → 1:1 循环，默认 3:4。比例按竖拿手机的方向标注。
- 取景框随比例变形，拍到的范围和看到的一致。
- 9:16 时取景画面铺满屏幕宽度，上下栏半透明叠在画面上（见待确认事项 5）。
- 切换比例时相机需要重新配置，画面会短暂黑一下。
- 录像模式下不显示画幅按钮，固定为 9:16。

**实现**

- 3:4 和 1:1 让相机按 4:3 输出，9:16 按 16:9 输出，通过 `setPreviewResolutionSelector()` 和 `setImageCaptureResolutionSelector()` 设置比例。
- 1:1 没有原生输出，靠裁剪实现：`CameraController` 会按 `PreviewView` 的可见范围自动裁剪照片（CameraX 的 ViewPort 机制）。取景框是正方形，拍出来的照片就是正方形。
- 画质影响：多数手机的传感器是 4:3，9:16 和 1:1 都是从中裁出来的，像素比 3:4 少约四分之一。

### 3.2 手电筒常亮

**交互**

- 后置镜头的闪光灯按钮变成四档：OFF → AUTO → ON → TORCH（见待确认事项 4）。TORCH 时闪光灯一直亮着，拍照时不再额外闪光。
- 录像模式下只有 OFF 和 TORCH 两档。
- TORCH 不记忆：切换镜头、切到后台或重新打开应用后都回到 OFF，避免一打开应用手电筒就亮。
- 设备没有闪光灯时（比如部分平板），后置镜头也不显示闪光灯按钮。现在的代码没有做这个判断。

**实现**

- 用 `CameraController.enableTorch()` 开关手电筒，按钮状态以 `getTorchState()` 为准。
- 用 `CameraInfo.hasFlashUnit()` 判断设备有没有闪光灯。

### 3.3 前置屏幕补光

**交互**

- 前置镜头下也显示闪光灯按钮，只有 OFF / ON 两档。
- 选 ON 后按快门，屏幕瞬间变白、亮度调到最高，拍完恢复。
- 前后镜头各自记住自己的闪光灯模式。
- 录像模式下，前置镜头不显示闪光灯按钮。

**实现**

- 使用 CameraX 1.4 起的屏幕补光：给 `PreviewView` 设置 `setScreenFlashWindow()`，把闪光模式设为 `FLASH_MODE_SCREEN`。提亮屏幕和曝光时机由 CameraX 控制。
- `PreviewView` 自带的白色遮罩只盖住取景框。如果实测补光不够，改用 `ScreenFlashView` 铺满整个屏幕。
- `FLASH_MODE_SCREEN` 只能用于前置镜头。切换镜头前，要先把闪光模式换成目标镜头支持的值。

## 第四期：录像

### 4.1 模式切换

**交互**

- 快门上方加「拍照」「录像」两个文字标签，点击切换，当前模式高亮。
- 录像模式下取景框固定为 9:16，隐藏定时和画幅按钮，闪光灯只有 OFF / TORCH。
- 切换模式时相机需要重新配置，画面会短暂黑一下。
- 每次打开应用都从拍照模式开始。

### 4.2 录制

**交互**

- 录像模式下快门变成红色圆点。点击开始录制，按钮变成红色方块，再点一次停止。
- 录制中顶栏只显示录制时长（比如 `00:12`）和闪烁的红点。
- 录制中不能切换镜头和模式；缩放、对焦、手电筒照常可用。
- 停止后视频保存到 `Movies/PureCam`，文件名规则和照片相同，扩展名为 `.mp4`。缩略图显示视频画面，点击用系统播放器打开。
- 切到后台时自动停止录制并保存。
- 因存储空间不足等原因保存失败时，弹出提示。
- 第一版不做：录像中拍照、暂停 / 继续、慢动作、延时摄影、4K、60 帧。

### 4.3 麦克风权限

**交互**

- 第一次切到录像模式时申请麦克风权限，不在启动时申请。
- 拒绝后仍然可以录像，只是没有声音。录像模式下显示一行提示「未开启麦克风，录像没有声音」，点提示可以再次申请；永久拒绝后改为跳转系统设置，和相机权限的处理方式一样。

### 4.4 实现

- 新增依赖 `camera-video`。清单里声明 `RECORD_AUDIO` 权限，并把麦克风声明为可选硬件（`android.hardware.microphone`，`required="false"`），不影响没有麦克风的设备安装。
- 拍照模式只启用 `IMAGE_CAPTURE`，录像模式只启用 `VIDEO_CAPTURE`，用 `setEnabledUseCases()` 切换。不同时启用两者，因为部分低端机不支持预览、拍照、录像三路同时工作。
- 用 `setVideoCaptureQualitySelector()` 指定 1080p，设备不支持时自动降级。
- 用 `startRecording()` 开始录制，传入 `MediaStoreOutputOptions` 和 `AudioConfig`。有麦克风权限时录音，没有时静音录制。没有权限却开启录音，CameraX 会直接抛异常。
- 从 `VideoRecordEvent` 里读取录制时长，并在结束事件里拿到保存结果。
- 前置录像要不要镜像，开发时对照前置照片的实际效果再定，保证两者一致。

## 代码结构调整

`CameraScreen.kt` 现在约 370 行，四期做完会大很多。建议在第一期顺带拆分：

| 文件 | 内容 |
| --- | --- |
| `camera/CameraScreen.kt` | 页面组装和权限判断（保留） |
| `camera/CameraControls.kt` | 顶栏、底栏的各个按钮和「⋯」面板 |
| `camera/ViewfinderOverlays.kt` | 对焦框、网格线、倒计时、变焦倍数 |
| `camera/MediaStorage.kt` | 由 `PhotoStorage.kt` 改名：照片和视频的保存、最近一条的查询 |
| `settings/CameraSettings.kt` | DataStore 设置读写 |
| `MainActivity.kt` | 增加音量键转发 |

拆分后同步更新 README 里的项目结构。

## 验证方式

- 每期完成后在真机上按本文的交互逐条验收。至少在最低支持的 Android 10 和一台较新系统的手机上各测一遍。
- 需要重点实测的机型差异：9:16 和 1:1 的成片范围、屏幕补光的亮度、能否缩小到 1x 以下。
- 闪光灯档位循环、变焦倍数格式、倒计时这类纯逻辑加单元测试。项目目前还没有测试，第一期顺带把测试目录建起来。

## 不在本次规划内

- 手动 ISO / 快门等专业参数：需要换成 `ProcessCameraProvider` 加 Camera2 互操作，改动大，单独规划。
- 完整的设置页：目前的设置项都放得进「⋯」面板，暂时不需要。
